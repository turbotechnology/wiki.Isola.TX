# Хранимые/составные/презентационные отчёты

Данные хранятся в объекте IData.
Для каждого отчёта описывается свой наследник IData, содержащий все необходимые поля.
(в будущем - это может быть хорошим местом для использования динамической диспетчеризации).

Для хранения IData может сериализироваться/десериализироваться (в json).

За заполнение IData отвечает класс-builder. 
Источниками данных может быть что угодно (Report/Query/etc.).
Для начала заполнение делается только на коде, в дальнейшем сможем заполнять IData в сессии.

Формы могут выгружаться в
 - tpl
 - xml
 - crf
 - xlsx

Выгрузка делается на базе шаблонов. Должны поддерживаться:
 - Обращение к свойствам IData
 - Обращение к произвольной функции
 - Условный оператор (определение видимости)
 - Циклы

Только для "экранных" форматов (tpl, crf)
 - Элемент "Разделы/мультитаб"
 - Элемент "Спойлер"

## Шаблонизатор tpl
Для tpl это будет что-то вроде печатных форм Т9.

1. Обращение к свойствам  
   Делается через вычислимые поля `#$Свойство` или `#$$Свойство`, где `$Свойство` - значение свойства в текущем контексте, а `$$Свойство` - значение в контексте IData.  
   Вычислимые поля могут быть редактируемыми. Для таких полей после изменения значения вызывается метод `IData.DoManualUpdate`, в него можно встраивать собственную логику.  
   В клетке шаблона может быть указан обработчик OnClick. В таком случае вызывается одноимённый метод `IData`, который должен иметь одну из следующих сигнатур:
   - `proc DrillDown`
   - `proc DrillDown(aContext :IData.TContext)`
   - `func DrillDown(Cell :TemplateCell; Action :Kernel.Template.ClickTypes) :Logical`   

2. Вызов произвольных функций.  
   Делается через вычислимые поля `#$$ИмяФункции(параметры)`. Функция вычисляется через Evaluate контексте IData. Если в параметры нужно передать ссылку на IData, то достаточно написать Self.  

3. Кнопки на бланке.  
   Если требуется выполнить какое-то действие по кнопке, то создаётся кнопка вида: `Наименование$Процедура(Параметры)`.
   Процедура так же вызывается через Evaluate контексте IData.

4. Команды  
   Если первая клетка строки является статической и в ней первый символ - `$`, то эта строка интерпретируется как управляющая конструкция.
   Управляющая строка скрывается и выполняет соответствующую ей команду. Команда, если не указано противного, действует до конца секции.  

Доступные команды:
 - `$secvis <условие>`  
   условие видимости секции (для невидимой секции дополнительные вычисления не производятся)  
   в качестве условия можно указывать не только логическое значение, но и целое, а так же массив/список
 - `$colvis <условие> <начиная с> <сколько>`  
   условие видимости для <сколько> столбцов <начиная с>  
   в качестве условия можно указывать не только логическое значение, но и целое, а так же массив/список  
   в секции может быть указано несколько команд `$colvis`
 - `$rowcount <контекст> <начиная с> <сколько>`  
   дублирует строки шаблона  
   параметр <контекст> может быть целочисленным, либо массивом/списком  
   дублирует <сколько> видимых строк <начиная с> указанной (параметры являются не обязательными и имеют значения по умолчанию 1 и ДлинаСекции соотвественно)
 - `$colcount <контекст> <начиная с> <сколько>`  
   дублирует столбцы шаблона
 - `$seccount <контекст> <сколько>`  
   дублирует секцию шаблона  
   (параметр <сколько> пока не реализовывается)
 - `$colcontext <контекст> <начиная с> <сколько>`  
   меняет контекст колонки для последующих <сколько> столбцов <начиная с>
 - `$version <версия>`  
   переключает обработку на указанную версию движка  
   <версия> может быть полным именем класса, а может быть строкой/числом (тогда ищется класс Tpl.Engine<версия>)  
 - `$loadframe <ключ>`  
   производит подзагрузку шаблона в текущий фрейм  
   имя встраиваемого шаблона берётся по ключу, из встроенного хранимого отчёта  
   если в типе отчёта такой ключ не найден или найден, но элемент не является хранимым отчётом, то загрузка не производится
 - Неизвестная команда рассматривается как комментарий (и скрывается).
 
#### Контексты
По умолчанию контекстом вычисления `$значений` является объект IData.
При замножении строк командами `$rowcount`, `$colcount`, `$seccount` происходит смена контекста на заданный, если в качестве параметра указана коллекция, а не целочисленное значение.
При этом можно обращаться к свойствам CurRow/CurCol/CurSec, которые возвращают порядковый номер строки, столбца и секции соответственно.
В коде будут доступны контекст текущей клетки `CurrentCtx :<TemplateCell>` и контекст нажатой кнопки `ClickCtx :<TemplateCell>`.

Для crf будет с одной стороны проще - расширим IControl свойством Формула.
С другой - для таблиц может получиться громоздко.

## Шаблонизатор xml/txt
Для текстовых форматов получается что-то типа упрощённой версии [smarty](https://www.smarty.net/syntax_comparison)/[jinja](https://jinja.palletsprojects.com/en/stable/templates/).
Возможно лучше не реализовывать ещё один шаблонизатор, а использовать xsd-схемы.

## Примеры
#### Пример 1
Шаблон:  
![](/img/blended1.png)  
Команда `$rowcount Ресурс 2 2` говорит, что к табличной части относятся две строки со второй начиная.
Количество элементов будет соответствовать коллекции Ресурс.
При этом для структуры IData возможны две интерпретации:
  - либо Ресурс состоит из объектов/Storage, содержащих поля Name, Sum, Description
  - либо Ресурс состоит из элементов простых типов, а Name, Sum, Description сами являются коллекциями
В итоговой строке выводится поле Total из IData.

Вариант А:
```
{
  Ресурс: [
    {Name: '', Sum: 0, Description: ''}
  ],
  Total: 0
}
```
Вариант Б:
```
{
  Ресурс: [''],
  Name: [''],
  Sum: [0],
  Description: [''],
  Total: 0
}
```

#### Пример 2
Шаблон:  
![](/img/blended2.png)  
Здесь замножаются не только строки, но и столбцы. При этом формулы `#$Sum` и `#$$Процес[CurSec].Ресурс[CurRow].ПоДнямРесурса[CurCol].Sum` обращаются к одному и тому же элементу.
Для структуры IData возможны несколько интерпретаций, приведу основную: 
  - коллекцию Процесс, включающую в себя поле Name и коллекции ПоДням, Ресурс
  - вложенная коллекция ПоДням содержит поле Дата
  - вложенная коллекция Ресурс содержит поле Name, а так же коллекцию ПоДнямРесурса, в которой есть поле Sum
```
{
  Процесс: [{
    Name: '',
    ПоДням: [
      {Дата: ''}
    ],
    Ресурс: [
      {Name: '', ПоДнямРесурса: [{Sum: 0}]}
    ]
  }]
}
```
