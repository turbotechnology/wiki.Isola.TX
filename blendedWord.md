## Шаблонизатор Word ver.1

В классе `OpenXml.Engine` объявлен метод 
`proc Render(aContext :Object; aTemplate, aFilename :String)`
`aContext` - корневой контекст, в котором вычисляются формулы.
`aTemplate` - имя файла-шаблона
`aFilename` - имя создаваемого файла (файл будет перезаписан)

Шаблонизатор работает с примечаниями. Он проходится по списку всех примечаний word-файла и заменяет их на вычисленное значение.
Подсвеченная строка является формулой, текст примечания - текстовым описанием. 
В сформированном документе и подсвеченная строка и примечание удаляются.
Возможны следующие варианты формул:
 - Команда - формула начинающаяся с символа `#`
 - Простая формула - формула вычисляемая через GetField в текущем контексте
 - Вычислимая формула - все остальные варианты

#### Команда
Команды предназначены для выполнения процедур. 
Планируются команды:
 - `#Контрагент` - смена текущего контекста на Контрагент
 - `#$$` - смена текущего контекста на корневой (исходный)
 - `#$$КлиентУК` - смена текущего контекста на КлиентУК корневого
 - `#$add <контекст>` - добавление элементов в список, либо строк в таблицу

В зависимости от того, где находится команда `#$add` она добавляет либо элементы списка, либо строки таблицы.
Параметр <контекст> должен быть либо коллекцией (подтаблица/массив/список), тогда он временно меняет текущий контекст, либо целочисленным, тогда текущий контекст не меняется.
Если количество добавляемых элементов равно 0, то список/таблица удаляется.
Неизвестная команда рассматривается как комментарий и из итогового файла удаляется.

#### Простая формула
Простая формула вычисляется через GetField в текущем контексте. 
Примеры простых формул:
 - `ОргСтруктура.Шифр` - значение поля ОргСтруктура.Шифр
 - `$sExtra` - значение доп.поля sExtra

#### Вычислимая формула
Вычисляется через Evaluate в текущем контексте.
Используются макросы:
 - `$` - текущий контекст
 - `$$` - корневой контекст
 - `$#` - индекс элемента коллекции (вне коллекции возвращает 0)

Если после макроса идёт идентификатор, то он интерпретируется как поле/доп.поле соответствующего контекста, иначе макрос заменяется на собственно контекст.
Примеры вычислимых формул:
 - `$$Код + '\' + $Код` - выполняется конкатенация поля Код корневого контекста и поля Код текущего контекста
 - `SomeClass.Somefunc($, $#)` - выполняется функция Somefunc класса SomeClass с параметрами: текущий контекст, индекс
